# 新手创作体验设计（红果创作）

目标用户：第一次做 AI 短剧、不懂剧本、分镜和模型参数的创作者。用户表达想法、查看结果、提出修改、确认关键内容；界面解释当前步骤、前置条件和下一步；后台继续使用现有版本、审核、任务、来源和成本规则。

视觉依据：任务说明中的文字规范。两张新手版设计图在执行会话中没有附件，也未在本机找到，本轮没有对照图片；颜色、圆角、字号、布局按文字规范实现。

## 原则

- **不复制业务实现。** 新手页面挂载高级工作台已有的组件（故事、剧本、角色/场地、场景/镜头、任务面板、多镜编排、成本），只增加说明、由服务器事实推导的步骤状态和一个主操作。保存、If-Match、幂等键、409 确认、审核状态机、任务轮询与重试、复用与主动重新生成、下载资格全部沿用原实现。
- **数据加载只写一次。** 工作台的项目基础数据读取、迟到响应丢弃和任务轮询提取到 `apps/web/src/lib/project-base.ts` 的 `useProjectBase`，高级工作台与新手流程共用。
- **状态来自服务器。** 步骤状态由 `apps/web/src/lib/beginner-steps.ts` 的纯函数从修订审核/新鲜度、分集剧本指针、已批准单镜成片、单集成片和任务推导；没有本地「完成」标记或固定百分比。读不到的事实保持未知。
- **主题。** `globals.css` 的 `.beginner` 作用域把共享色板变量换成浅色（底色 #F7F6F2、卡片 #FFFFFF、正文 #24232A、主操作 #D34846、分隔线 #E7E5E0、选中浅珊瑚红、12px 圆角、正文 16px），挂进来的原组件随之变色，无需改它们的类名。

## 路由

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `/` | 开始创作 | 「你的故事，从一句话开始」，有作品时显示「继续上次创作」 |
| `/create` | 开始创作 | 同上，导航高亮「开始创作」；灵感中心带 `?direction=1` 进入 |
| `/studio` | 我的作品 | 卡片：名称、文字封面、当前阶段、待处理事项、继续创作、高级编辑 |
| `/categories` | 灵感中心 | 原分类中心，不改。「用这个方向新建作品」改指向 `/create?direction=1` |
| `/help` | 帮助 | 常见问题；服务状态仍在 `/status` |
| `/projects/[id]/create?step=` | 新手五步流程 | `story`/`script`/`cast`/`sample`/`final` |
| `/projects/[id]` | 高级编辑 | 原工作台不变，页头增加「我的作品」「新手模式」链接 |

旧链接（`/projects/[id]?focus=…`、`/categories`、`/status`、`/preview`）继续有效。原 `ProductHome` 与 `ProjectHome` 组件保留（及其测试），只是不再挂在 `/` 和 `/studio`。

## 页面—现有能力映射

| 新手界面 | 调用的现有能力 | 持久化 |
| --- | --- | --- |
| 开始构思 | 无请求，只展开确认区 | 本标签页草稿（sessionStorage，原新建作品草稿槽位） |
| 示例模板 / 看看灵感 | 无请求；静态示例并标注「示例」 | 不保存 |
| 建议名称 | 纯函数按规则截取想法开头，页面说明不是 AI 生成 | 不保存，直到确认创建 |
| 确认创建作品 | `POST /projects` `{title, premise}` + 草稿幂等键；失败/不确定保留输入与原键 | 服务器 |
| 我的作品卡片进度 | `GET /projects`；每个作品读 stories/episodes/characters/locations/workflow-runs，已批准剧本的集再读 compose-candidates 与 composites（同时最多 2 个作品） | 只读 |
| 第 1 步 定故事 | 原 `StoryPane`：编辑器、编剧助手（准备要求、导入、预览、比较、采纳到草稿）、保存新版本（If-Match）、版本栏审核 | 服务器版本；未保存为本标签页草稿 |
| 第 2 步 看剧本 | 原 `ScriptPane`（逐集），集标签显示各集真实状态 | 同上 |
| 第 3 步 定人物 | 原 `EntityPane`（角色/场地），其中角色参考图面板按原接口运行，草案未执行时显示待配置 | 同上 |
| 第 4 步 试一段 | `GET …/scenes` 选场景；原 `ScenePane`（镜头、Mock 素材生成、单镜预检与合成、成片审核）；原 `TaskDrawer`（Mock 生成场景/镜头、取消、符合规则的重试） | 服务器 |
| 第 5 步 出成片 | 原 `EpisodeComposePreflight`（加入/上移/下移/移除、总时长、预检、提交、任务、审核、MP4 与来源清单下载、历史成片）；原 `ProjectCostSummary` | 服务器 |
| 每步主按钮 | 只做导航或定位：滚动并聚焦到编辑器、版本栏审核区、镜头选择区，打开任务面板，或进入下一步。不会自己保存、审核或重试 | — |
| 稍后继续 | 有未保存修改时说明草稿只在本标签页，可回去保存或保留草稿离开 | — |
| 高级编辑 | 链接到同一内容的工作台 `focus` | — |

## 步骤状态

| 状态 | 判定（示例：一个修订） |
| --- | --- |
| 未开始 | 前置步骤还没有完成，或本作品还没有该内容 |
| 待补充 | 应有的内容还没有（无剧本、无角色、无单镜成片等） |
| 待确认 | 当前修订 DRAFT/IN_REVIEW，或批准指针不是当前修订；单镜合成成功但还没有已批准成片；当前单集成片 DRAFT |
| 处理中 | 对应媒体或合成任务在排队/运行 |
| 需要处理 | 当前修订被退回；最近一次单镜合成失败或取消 |
| 已完成 | 当前修订已批准且 CURRENT；有已批准的当前单镜成片；当前单集成片已批准 |
| 来源已更新 | 当前修订 STALE；单集只有已失效的已批准成片 |

多项合并时按「来源已更新 > 需要处理 > 处理中 > 待补充 > 待确认 > 未开始 > 已完成」取最需要用户处理的一项。状态旁带符号（✓ ？ ！ ↻ ＋ … ○），不只靠颜色区分。

## 已知限制（本轮）

- 任务视图不含单集合成属于哪一集：有单集合成在运行时，所有还没有当前成片的集都显示「处理中」。
- 项目列表接口没有封面资产，卡片一律用文字封面。
- 场景列表接口不返回标题，试一段按列表顺序显示「场景 1、2…」。
- 嵌入的原组件仍显示部分英文状态（如 `DRAFT`）和折叠的「高级 JSON」；没有改写它们。
- 画风没有独立持久化字段：页面只提示写进角色/场地描述，不提供「保存画风」。
- 没有自然语言修改的执行接口：试一段只说明改镜头文字后重新生成，不假装自动执行。
- 没有预算控制与报价：费用只展示已记录结果。
