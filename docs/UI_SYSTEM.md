# 红果创作 · 全站界面规范

本规范覆盖整个 Web 产品，不仅是新手五步。统一暖白底、珊瑚红主操作、深灰文字；媒体画面和题材插图可以保留自己的颜色。业务判断仍由已有组件和服务端完成。

## 唯一来源

- `globals.css` 定义颜色、尺寸、圆角、焦点与语义反馈 token；不保留第二套暗色应用主题。
- `CreatorShell` 是唯一品牌、导航、移动抽屉和内容框架。`BeginnerShell` 仅转发参数，不维护另一套布局。
- 品牌统一为「红果创作」。导航统一为「我的作品 / 开始创作 / 灵感中心 / 界面示例 / 帮助 / 服务状态」。
- 页面标题 32px（手机 28px），正文 15–16px，辅助信息至少 12px；正文与背景保持清晰对比。
- 页面间距 8px 为基础；桌面内容区最大 1320px、手机边距 16px。复杂编辑页面使用同样 token，可占满剩余宽度。
- 主按钮使用 `--studio-accent`，次按钮白底描边，文字操作无填充。可点击控件至少 44px 高，禁用、焦点、选中、加载、错误均有明确表现。
- 卡片、编辑区、版本对比、审核、任务、配音/媒体、合成、成本、弹窗使用同一组边框/表面/圆角。布局可随内容变化，不另造品牌或主题。

## 完整覆盖清单

| 页面 | 桌面 / 390px | 共用内容 |
| --- | --- | --- |
| `/`、`/create` | 必查 | 想法输入、模板、确认、失败与重试 |
| `/studio` | 必查 | 作品卡片、空态、读取失败、任务状态 |
| `/categories` | 必查 | 题材、标签、方向、详情弹窗 |
| `/preview` | 必查 | 故事、人物、分镜、成片四个示例页签 |
| `/help`、`/status` | 必查 | 指南、服务读取与失败 |
| `/projects/[id]/create` | 五步分别必查 | 草稿、审核、媒体、合成、下载 |
| `/projects/[id]` | 各编辑区必查 | 高级目录、版本、助手、任务、成本 |

验收需记录实际页面状态，不能仅凭 200 或没有横向滚动判定设计完成。本地视觉验收使用模拟 API 时必须标明；原有真实 API / Worker / PostgreSQL / FFmpeg CI 门槛保持。不得为截图伪造正式产品数据或开启未验收能力。

## 业务保护

不改变保存/If-Match/409、草稿恢复、审核状态、能力门控、轮询退避、任务幂等、来源失效、费用与下载资格。不新增依赖、Migration、SQL 草案执行或真实模型调用。页面采用相同主题不代表相关能力已开启。
