# 红果创作 · 全站界面规范

本规范覆盖整个 Web 产品，不仅是新手五步。统一暖白底、珊瑚红主操作、深灰文字；媒体画面和题材插图可以保留自己的颜色。业务判断仍由已有组件和服务端完成。

## 唯一来源

- `globals.css` 定义颜色、尺寸、圆角、焦点与语义反馈 token；不保留第二套暗色应用主题。
- `CreatorShell` 是唯一品牌、导航、移动抽屉和内容框架。`BeginnerShell` 仅转发参数，不维护另一套布局。
- 品牌统一为「红果创作」。导航统一为「我的作品 / 开始创作 / 界面示例 / 帮助 / 服务状态」。灵感（题材、标签、方向说明）是「开始创作」页内的一个区块，不再是并列入口。
- 页面标题 32px（手机 28px），正文 15–16px，辅助信息至少 12px；正文与背景保持清晰对比。
- 页面间距 8px 为基础；桌面内容区最大 1320px、手机边距 16px。复杂编辑页面使用同样 token，可占满剩余宽度。
- 主按钮使用 `--studio-accent`，次按钮白底描边，文字操作无填充。可点击控件至少 44px 高，禁用、焦点、选中、加载、错误均有明确表现。
- 卡片、编辑区、版本对比、审核、任务、配音/媒体、合成、成本、弹窗使用同一组边框/表面/圆角。布局可随内容变化，不另造品牌或主题。

## 完整覆盖清单

| 页面 | 桌面 / 390px | 共用内容 |
| --- | --- | --- |
| `/`、`/create` | 必查 | 想法输入、模板、确认、失败与重试 |
| `/studio` | 必查 | 作品卡片、空态、读取失败、任务状态 |
| `/categories` | 必查 | 307 到 `/create?direction=1#inspiration`；题材、标签、方向说明在 `/create` 灵感区 |
| `/preview` | 必查 | 故事、人物、分镜、成片四个示例页签 |
| `/help`、`/status` | 必查 | 指南、服务读取与失败 |
| `/projects/[id]/create` | 五步分别必查 | 草稿、审核、媒体、合成、下载 |
| `/projects/[id]` | 各编辑区必查 | 高级目录、版本、助手、任务、成本 |
| `/projects/[id]/writing` | 必查 | 生成进度、结果不确定、故事待审核、逐集写入与冲突 |

验收需记录实际页面状态，不能仅凭 200 或没有横向滚动判定设计完成。本地视觉验收使用模拟 API 时必须标明；原有真实 API / Worker / PostgreSQL / FFmpeg CI 门槛保持。不得为截图伪造正式产品数据或开启未验收能力。

## 业务保护

不改变保存/If-Match/409、草稿恢复、审核状态、能力门控、轮询退避、任务幂等、来源失效、费用与下载资格。不新增依赖、Migration、SQL 草案执行或真实模型调用。页面采用相同主题不代表相关能力已开启。

## 统一界面细则（2026-10-09）

- 沿用原有暖白与珊瑚红方向，底色 `#f6f5f2`、主操作 `#c94438`、正文 `#242824`。全站直接引用 `--studio-*`，不在标题创作页单独定义一套品牌色。
- 导航分为「创作工作区」和「了解与帮助」。桌面用同一个页眉，手机用同一个导航抽屉，保留 Escape 关闭与焦点返回。
- 主面板圆角 18px，内层分组 12px，控件 10px；正文与辅助信息、主操作与次操作有固定层级。按钮和主要输入控件最小高度 44px。
- 高级编辑、编剧助手、审核、单镜和多镜合成、已记录成本，以及标题创作的配置与结果，使用共用的表面、边框和反馈颜色。
- 标题创作进度在桌面采用两列、手机采用单列。绿色只表示对应状态已经完成；结果不确定用警示色，错误用错误色。生成完成、故事审核和剧本逐集写入仍是不同事实，样式不得把它们合并。
- 当前 `/` 与 `/create` 均进入 `BeginnerStart`。旧 `ProductHome` 不在当前路由中，本轮不更换入口，也不把未挂载的页面当作交付。
- 本次本地视觉核验与截图见 `CREATOR_UI_FINISH_REPORT.md`。截图里的作品和 API 响应是视觉夹具，不是实际模型生成或服务器上的项目。

## 创作入口合并（2026-10-09）

- `/create`（及 `/`）是唯一创作入口：标题区 →「AI 一键创作」与「写下想法」表单 → 内嵌灵感区「还没想法？选一个故事方向」→ 确认创建。
- 灵感区默认 4 个方向卡片，「查看更多方向」在本页展开全部 12 个；点卡片在本页显示说明、问题、推荐标签，「更多标签」可选全部 64 个。只有点「用这个方向」才把方向追加到「故事想法」末尾。
- 更换或移除只删除本页追加的、仍原样存在的方向文字；文字被改过时正文保持不变并提示。提交中灵感区只能查看，不能改动。
- 旧 `/categories` 307 到 `/create?direction=1#inspiration`。`CategoryCenter` 组件及其测试保留但不再挂载路由。详见 `UNIFIED_CREATE_REPORT.md`。
