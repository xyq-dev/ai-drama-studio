# 商业创作者界面

AI Drama Studio 的用户是需要创作 AI 短剧的人。第一批是独立创作者。品牌名继续用 AI Drama Studio，不使用暗示其他平台授权的名称。

## 页面

| 路径 | 作用 |
| --- | --- |
| `/` | 产品首页。说明剧本、分镜、素材、成片，并进入创作中心或界面示例。 |
| `/studio` | 创作中心。读取真实项目列表，新建作品只提交标题和故事梗概。 |
| `/categories` | 分类中心。12 个参考题材、6 组共 64 个标签；支持搜索、题材说明与创作方向整理。选择只保存在当前浏览器，可复制到梗概或编剧助手，不写入项目分类字段。「用这个方向新建作品」只在 URL 带 `direction=1` 标记，由用户在新建作品里点击加入梗概（重复点击不重复追加）；创建成功后方向按实际 projectId 保存在本浏览器，故事编剧助手可主动「带入分类方向」到题材，原有内容保留，输入变化后旧指令按既有规则失效。 |
| `/projects/[projectId]` | 创作工作台。沿用已有审核、版本、任务和成片逻辑，按故事、角色、分镜、合成来导航。 |
| `/preview` | 没有后端时也能打开的只读示例。不请求 API，不创建项目。 |
| `/status` | 服务状态，放在帮助入口。 |

桌面是左侧导航、中央创作区和可折叠检查面板。窄屏使用抽屉导航。状态同时有文字。

## 本轮完成

- 首页、创作中心、工作台布局和只读预览已经接到 Web。
- 创建草稿、失败后的同一幂等键、游标分页、加载失败和重试保持原语义。
- 已记录成本仍是账本记录，不是余额或应付费用。
- Mock 输出标明为演示素材，不称为真实 AI 生成。
- 当前试制范围仍是固定三集。
- 分类中心采用用户参考图的红白配色、题材插画卡片和规则侧栏；统计来自随代码发布的参考词库，不是项目数量。一级分类固定，页面不提供无持久化能力的“新建分类”。已有页面保留原有创作逻辑与主题。

本轮没有登录、会员、积分、充值、团队或模型选择器。当前仍是固定工作区。

## 后续

- 账户隔离：真实身份，以及项目只对创建者可见。
- 真实 Provider：在单独授权后替换演示素材。
- 集数参数化：不再把三集写死在界面和校验里。
- 用量和付费计划：在有真实调用记录之后再设计，不提前承诺价格或商用授权。
