## 页面与按钮行为

| 入口 / 控件 | 行为 |
| --- | --- |
| 我的作品 | `/studio`；默认全部分类，展示真实作品列表；本轮无全量状态筛选标签 |
| 分类 | 服务端持久保存分类标题及作品归属；与搜索、排序组合，作用于服务端全量作品 |
| 行内阶段 | 保留作品真实阶段与状态文字；不把当前分页统计当作全量状态计数 |
| 搜索、排序、刷新 | 基于当前条件由服务端查询全量作品；错误重试不清空用户筛选 |
| 新建分类 | 进入分类管理；不能只显示一个无效按钮 |
| 开始创作 | 进入既有创作入口；继续创作或查看作品进入对应项目 |
| 设置 | `/settings/storage`；`/settings` 为设置入口 |
| 服务商 | 腾讯云 COS、阿里云 OSS、Amazon S3、MinIO 四种；切换后使用对应参数和凭据名称 |
| 保存草稿 | 保存参数，不切换正在使用的存储 |
| 检测连接 | 仅对已保存且未修改的草稿可用；写入、读回并清理临时对象 |
| 启用此配置 | 仅检测通过的同一版本在有效期内可用；确认后切换新文件写入位置 |
| 重新读取 | 结果不确定、冲突或读取失败时恢复服务端状态；有未保存改动时明确确认 |

本轮相较原效果图有两项明确收窄，Figma 已同步：作品页移除「全部 / 创作中 / 待确认 / 已完成」全量状态标签，保留分类、搜索、排序的服务端全量查询及行内真实阶段；存储页不提供「自定义访问域名」，私有素材统一通过本站登录鉴权后读取。

MinIO 允许配置 HTTPS Endpoint，但本版本固定使用路径式寻址。界面仅显示只读说明「寻址方式：路径式。本版本的 MinIO 配置使用路径式寻址。」，没有可取消的复选框。COS、OSS、S3 按地域生成 Endpoint。自定义 CDN 域名暂不开放。

启用后新文件使用新配置；已开始的上传继续使用原配置；已有文件保持原存储引用。旧本地合成文件保留原下载路径，本轮不迁移历史媒体，也不承诺提供自动迁移功能。

## 必要状态

| 区域 | 验收要求 |
| --- | --- |
| 列表加载 | 保留版式，展示读取状态或骨架；不显示假数据作为真实内容 |
| 列表空白 | 区分无作品和当前条件无结果；提供开始创作或清除筛选入口 |
| 列表错误 | 保留当前条件，可重试；封面失败不影响标题和继续入口 |
| 设置加载 / 未初始化 | 未读到真实配置前锁定写操作，不显示示例 MinIO 为当前生产配置 |
| 密钥 | 不回显保存值；保留旧凭据或同时更换两项；不写入浏览器持久存储 |
| 未保存 / 未检测 | 检测或启用按钮按依赖禁用，文字解释下一步 |
| 检测失败 / 过期 | 展示失败或过期状态；通过结果有效 15 分钟；改参数后重新保存、检测 |
| 提交中 / 回执不确定 | 禁止重复提交；冲突或结果不明时先重新读取状态 |
| 登录 / 权限 | 遵循现有站点认证和服务端权限；未登录或无权限不允许修改 |
| 键盘与辅助技术 | 原生按钮/标签、可见焦点、输入关联标签、状态提示；确认弹窗 Escape 关闭并恢复焦点 |

## 视觉与实现验证的界限

已对 Figma 的四张主画板截图核验，修正了桌面标题高度、桌面页面底部边界和手机表单高度；核对了 Auto Layout、组件实例、可编辑文字和无整页位图。桌面作品与设置的主要内容容器、两张手机画板均检查了子元素边界，未发现溢出。最终移除全量状态标签、将 MinIO 寻址方式改为只读后，已再次截图检查相关桌面/手机作品画板和 MinIO 说明，结构检查未发现溢出。

设计稿中加载、空白、错误和权限等状态在交接板中定义；未声称每种状态均另绘完整画板，也未制作可点击的 Figma Prototype。真实页面应在 1440px 和 390px 宽度、相同数据状态下截图对照，并验证搜索/分类、作品跳转、保存/检测/启用的真实行为。

本文件仅记录设计交接。产品测试、真实服务商连通、Git 提交/推送、部署和数据库 Migration 的结果以本轮执行报告为准；Figma 截图通过不等于这些操作已完成。
